# testSEO

CRM Open Source Italiano
Un sistema di gestione delle relazioni con i clienti (CRM) completamente open source progettato specificamente per le esigenze del mercato italiano.

Caratteristiche principali
✅ Interfaccia in italiano: Completamente localizzato per utenti italiani
📱 Responsive design: Accessibile da qualsiasi dispositivo
🔒 Conforme GDPR: Rispetta tutte le normative sulla privacy europee e italiane
📊 Report avanzati: Visualizzazione dati personalizzabile
🔄 Integrazioni native: Compatibile con i principali servizi e software italiani
Installazione
bash
git clone https://github.com/tuoUsername/crm-italiano.git
cd crm-italiano
npm install
npm start
Configurazione
Modifica il file config.json con i tuoi parametri:

json
{
  "db": {
    "host": "localhost",
    "user": "admin",
    "password": "password",
    "database": "crm_db"
  },
  "app": {
    "port": 3000,
    "debugMode": false
  }
}
